# 📋 Moony MVP 需求文档

> 版本：v1.0 | 日期：2026-03-29 | 状态：规划中

---

## 1. 文档概述

### 1.1 目的
本文档定义 Moonly MVP 产品的功能需求、非功能需求、用户故事及验收标准。

### 1.2 产品背景
Moonly 是一款面向海外市场的 AI 情感陪伴工具，目标用户为 18-35 岁单身男女。

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| **用户** | 通过网页访问 Moonly 的访客/注册用户 |
| **AI 助手** | Moonly 的核心 AI 陪伴角色 |
| **情绪打卡** | 用户每日记录心情的功能 |
| **会话** | 用户与 AI 的一次对话交互 |
| **Pro 用户** | 付费订阅用户 |

---

## 2. 用户角色

### 2.1 访客用户（未登录）
- 定义：打开 Moonly 但未注册/登录的用户
- 权限：仅可体验 3 条免费对话
- 转化目标：引导注册成为正式用户

### 2.2 注册用户（免费）
- 定义：完成注册的用户
- 权限：每天 10 条对话、情绪打卡、基础记忆
- 限制：有广告或功能限制，引导升级 Pro

### 2.3 Pro 用户（付费）
- 定义：完成付费订阅的用户
- 权限：无限对话、高级情绪分析、优先新功能
- 价格：$9.9/月 或 $79/年

## 3. 功能需求

## 4. 技术架构

| 层级 | 技术方案 |
|------|---------|
| 部署 | Cloudflare Pages / Workers |
| 数据库 | 无持久化，纯内存 |
| 图片处理 | Remove.bg API |
| AI 引擎 | Claude API / GPT-4o |
